# 📋 Bewerbungssystem – Allgemeine Regeln

Appy ist der **einzige** Bot für Bewerbungen. Diese Regeln gelten für **alle** Formulare ausnahmslos.

---

## ✍️ Freitext-Felder

Für **jedes** textbasierte Pflichtfeld gilt:

- **Minimum: 50 Wörter**
- **Maximum: 250 Wörter**
- **Keine anderen Wortgrenzen** – keine Ausnahmen, nicht pro Formular abweichend

Betroffen sind **alle** offenen Fragen, darunter ausdrücklich:
Motivation · Erfahrungen · Stärken · Schwächen · Regelverständnis · Konfliktfragen · Fachfragen · Fallbeispiele · Teamleitungsfragen · sonstige offene Fragen

Appy blockiert Antworten außerhalb des Bereichs mit Hinweis: *"Deine Antwort muss zwischen 50 und 250 Wörtern liegen (aktuell: X Wörter)."*

---

## 🎛️ Auswahlfelder

Für diese Felder werden **Auswahlfelder (Dropdowns)** verwendet – **keine** Wortbegrenzung:

- Alter
- Zeitzone
- Online-Zeit
- Verfügbarkeit
- Ja/Nein-Fragen
- Multiple Choice

---

## ☑️ Checkboxen

Für Bestätigungen werden **Pflicht-Checkboxen** verwendet (z. B. "Ich bestätige, dass meine Angaben korrekt sind.").

---

## 📊 Bewerbungsstatus

| Status | Bedeutung |
|---|---|
| 🟡 In Prüfung | Eingereicht, wartet auf das Team |
| 🔵 Rückfrage | Team hat eine Nachfrage gestellt |
| 🟠 Vorstellungsgespräch | Gespräch eingeladen (Admin/Teamleitung) |
| 🟢 Angenommen | Angenommen – Rolle wird vergeben |
| 🔴 Abgelehnt | Abgelehnt – Grund wird dokumentiert |
| ⚫ Zurückgezogen | Bewerber hat zurückgezogen |

---

## 🔄 Ablauf (15 Schritte)

```
1.  Bewerber öffnet Bewerbung           → Button in 📋・bewerbungen
2.  Appy zeigt Formular                 → privater Bewerbungsbereich
3.  Bewerber beantwortet alle Pflichtfelder
4.  Appy prüft Pflichtfelder            → fehlende Felder markieren
5.  Appy prüft Wortgrenzen              → 50–250 Wörter
6.  Bewerbung wird eingereicht
7.  Bewerbungs-ID wird erstellt         → z. B. #APP-1042
8.  Status: 🟡 In Prüfung               → 📥・bewerbungs-status
9.  Weiterleitung an zuständiges Team   → 📋・bewerbungen-team
10. Team prüft die Bewerbung
11. optional: Rückfrage                 → Status 🔵
12. optional: Vorstellungsgespräch      → Status 🟠
13. Entscheidung                        → 🟢 Angenommen ODER 🔴 Abgelehnt
14. Bewerber wird automatisch informiert (DM + Status-Channel)
15. Bei Annahme: passende Rolle vergeben + Einstiegsrang festlegen
    Bewerbung wird archiviert           → 🗄️ Archiv (nur Serverleitung)
```

---

## ✅ Entscheidung bei Annahme

- Status auf 🟢 Angenommen
- Bewerber benachrichtigen
- entsprechende Rolle vergeben (Fraktions- oder Team-Rolle)
- Einstiegsrang festlegen (z. B. "Anwärter", "Probe-Mitglied")
- zuständiges Team informieren
- Bewerbung archivieren

## ❌ Entscheidung bei Ablehnung

- Status auf 🔴 Abgelehnt
- Bewerber benachrichtigen
- Ablehnungsgrund dokumentieren
- Bewerbung archivieren
