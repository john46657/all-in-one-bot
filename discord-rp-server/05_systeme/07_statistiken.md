# 📊 Statistiken (Statbot)

**Bot:** Statbot (einziger Statistik-Bot) · **Keine** XP, keine Economy.

---

## 📈 Dashboards

| Dashboard | Channel(s) |
|---|---|
| Message-Aktivität | `💬・allgemein`, `🎮・gaming`, `📸・bilder` |
| Voice-Aktivität | `🔊・Lobby`, `🎮・Gaming`, `💬・Talk`, `🎵・Musik` |
| Member-Aktivität | `👤・member-logs` (read-only Statistik-Panel) |
| Fraktions-Aktivität | private Fraktionsbereiche (je Fraktion) |

---

## 📅 Reports

- **Wöchentlicher Report** (sonntags 20 Uhr) → `📢・team-news`
  - Aktivste Mitglieder, aktivste Channels, Voice-Stunden, Neuzugänge/Abgänge
- **Monatsreport** (1. des Monats) → `📋・server-informationen` (Zusammenfassung)

---

## 📉 Ranking

Statbot betreibt die **einzige öffentliche Aktivitäts-Rangliste**:
- Channel: `🏆・economy-ranking` wird **nicht** verwendet (UnbelievaBoat)
- Statbot-Ranking-Channel: `📊・statistik-ranking` (neu anlegen)

---

## ⚙️ Einstellungen

- Erfassung: Nachrichten, Voice-Minuten, Reaktionen (keine Inhalte!)
- Keine Speicherung von Nachrichtentexten
- Discord-Invite-Tracking aus
